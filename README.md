## 💡 What is Country Explorer?  
Ever dreamed of being a digital traveler? 🧳✈️  
With **Country Explorer**, you can instantly learn about **any country’s flag, population, capital, languages, currency, and even tourism highlights** — all in one simple, interactive app.  

Whether you’re:  
- 🌎 A curious explorer,  
- 🏫 A student doing research,  
- 📊 A marketer studying global trends,  
- Or just a travel dreamer ✨...  

**This app is your personal passport to the world.**  

---

## 🚀 Features  
✅ Search any country instantly  
✅ Get detailed info: population, languages, capital, region, area  
✅ See the **official flag** 🏳️  
✅ Discover **tourism highlights** straight from Wikipedia 🏛️  
✅ Sleek, fast, and beginner-friendly interface with Streamlit
